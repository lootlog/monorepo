## Jak działają uprawnienia?

Lootlog posiada szczegółowy system uprawnień, który pozwala precyzyjnie kontrolować, co poszczególni członkowie klanu mogą robić. Uprawnienia przypisuje się do ról, a role — do członków.

## Hierarchia ról

System rozróżnia cztery poziomy dostępu:

| Rola | Opis |
| --- | --- |
| **Właściciel (Owner)** | Pełna kontrola nad klanem. Może wszystko, włącznie z ręczną edycją punktów w eventach. |
| **Administrator (Admin)** | Zarządzanie lootlogiem — nadawanie uprawnień, edycja konfiguracji. Ma dostęp do wszystkich funkcji. |
| **Moderator (Manage)** | Zarządzanie lootlogiem — usuwanie/edycja lootów, timerów i innych danych. |
| **Dostęp (Access)** | Podstawowe uprawnienie pozwalające na dostęp do danego lootloga klanu. |

> **Dziedziczenie:** Właściciel automatycznie ma wszystkie uprawnienia Administratora. Administrator ma wszystkie uprawnienia Moderatora. Moderator ma uprawnienie Dostępu.

## Lista uprawnień

### Dostęp i administracja

| Uprawnienie | Opis |
| --- | --- |
| `LOOTLOG_ACCESS` | Podstawowy dostęp do aplikacji klanu |
| `LOOTLOG_MANAGE` | Moderowanie — edycja i usuwanie danych |
| `ADMIN` | Pełne zarządzanie klanem |
| `OWNER` | Właściciel klanu — najwyższy poziom |

## Zarządzanie rolami

### Tworzenie roli

1. Przejdź do ustawień klanu → Role
2. Kliknij "Dodaj rolę"
3. Nadaj nazwę roli
4. Zaznacz uprawnienia, które chcesz przypisać
5. Zapisz rolę

### Przypisywanie ról

1. Przejdź do ustawień klanu → Członkowie
2. Znajdź członka
3. Przypisz mu rolę

Członek może mieć wiele ról — jego uprawnienia to suma uprawnień ze wszystkich przypisanych ról.

### Podgląd tytanów i herosów

Uprawnienia z przyrostkiem `_TITANS_READ` i `_HEROES_READ` kontrolują dostęp do informacji o najsilniejszych potworach. Klan może przyznawać te uprawnienia tylko zaufanym członkom, aby chronić informacje strategiczne.

> **Konfiguracja uprawnień eventowych:** Uprawnienia eventowe (`EVENTS_*`) konfigurujesz w ustawieniach klanu → Role → wybrana rola → sekcja "Eventy". Więcej o eventach w sekcji [Eventy klanowe](/docs/events).
