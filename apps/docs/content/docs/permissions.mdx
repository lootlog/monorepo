title: Role i uprawnienia
description: Kontroluj dostęp członków klanu za pomocą ról opartych na kanonicznych uprawnieniach Lootlog.
---

Uprawnienia są przypisywane do ról, a role do członków. Członek mający kilka
ról otrzymuje sumę ich uprawnień.

## Poziomy nadrzędne

| Uprawnienie      | Znaczenie                                   |
| ---------------- | ------------------------------------------- |
| `OWNER`          | Właściciel klanu i najwyższy poziom dostępu |
| `ADMIN`          | Administracja klanem i konfiguracją         |
| `LOOTLOG_MANAGE` | Zarządzanie danymi Lootlog                  |
| `LOOTLOG_ACCESS` | Podstawowy dostęp do strefy klanu           |

<Callout type="warning" title="Zasada najmniejszego dostępu">
  Nie nadawaj `ADMIN` lub `LOOTLOG_MANAGE` tylko po to, aby odblokować jeden
  widok. Wybierz najwęższy zestaw uprawnień potrzebny danej roli.
</Callout>

## Kanoniczna lista uprawnień

Poniższe identyfikatory odpowiadają wartościom używanym przez aplikację.

### Łupy

| Uprawnienie                 | Zakres                   |
| --------------------------- | ------------------------ |
| `LOOTLOG_LOOTS_READ`        | Odczyt łupów             |
| `LOOTLOG_LOOTS_WRITE`       | Dodawanie i zmiana łupów |
| `LOOTLOG_LOOTS_TITANS_READ` | Odczyt łupów z tytanów   |
| `LOOTLOG_LOOTS_HEROES_READ` | Odczyt łupów z herosów   |

### Timery

| Uprawnienie                  | Zakres                 |
| ---------------------------- | ---------------------- |
| `LOOTLOG_TIMERS_READ`        | Odczyt timerów         |
| `LOOTLOG_TIMERS_WRITE`       | Tworzenie timerów      |
| `LOOTLOG_TIMERS_RESET`       | Resetowanie timerów    |
| `LOOTLOG_TIMERS_DELETE`      | Usuwanie timerów       |
| `LOOTLOG_TIMERS_TITANS_READ` | Odczyt timerów tytanów |
| `LOOTLOG_TIMERS_HEROES_READ` | Odczyt timerów herosów |

### Rezerwacje i członkowie

| Uprawnienie                   | Zakres                        |
| ----------------------------- | ----------------------------- |
| `LOOTLOG_RESERVATIONS_READ`   | Odczyt rezerwacji             |
| `LOOTLOG_RESERVATIONS_WRITE`  | Tworzenie i zmiana rezerwacji |
| `LOOTLOG_MEMBERS_READ`        | Odczyt listy członków         |
| `LOOTLOG_ONLINE_PLAYERS_READ` | Odczyt listy graczy online    |

### Czat

| Uprawnienie                | Zakres                          |
| -------------------------- | ------------------------------- |
| `LOOTLOG_CHAT_READ`        | Odczyt czatu                    |
| `LOOTLOG_CHAT_WRITE`       | Wysyłanie wiadomości            |
| `LOOTLOG_CHAT_TITANS_READ` | Dostęp do informacji o tytanach |
| `LOOTLOG_CHAT_HEROES_READ` | Dostęp do informacji o herosach |

### Powiadomienia

| Uprawnienie                         | Zakres                   |
| ----------------------------------- | ------------------------ |
| `LOOTLOG_NOTIFICATIONS_READ`        | Odczyt powiadomień       |
| `LOOTLOG_NOTIFICATIONS_SEND`        | Wysyłanie powiadomień    |
| `LOOTLOG_NOTIFICATIONS_TITANS_READ` | Powiadomienia o tytanach |
| `LOOTLOG_NOTIFICATIONS_HEROES_READ` | Powiadomienia o herosach |

### Eventy

| Uprawnienie             | Zakres                     |
| ----------------------- | -------------------------- |
| `LOOTLOG_EVENTS_READ`   | Odczyt eventów i rankingów |
| `LOOTLOG_EVENTS_WRITE`  | Samodzielne przypisania    |
| `LOOTLOG_EVENTS_MANAGE` | Zarządzanie eventami       |

### Dokumenty

| Uprawnienie          | Zakres                              |
| -------------------- | ----------------------------------- |
| `LOOTLOG_DOCS_READ`  | Odczyt dokumentów klanu             |
| `LOOTLOG_DOCS_WRITE` | Tworzenie i zmiana dokumentów klanu |

## Utwórz rolę

1. Otwórz **Klan → Ustawienia → Role**.
2. Wybierz dodanie roli.
3. Nadaj nazwę opisującą odpowiedzialność, nie konkretną osobę.
4. Zaznacz wymagane uprawnienia.
5. Zapisz rolę i przypisz ją wybranym członkom.

## Sprawdź rezultat

Przetestuj rolę na koncie bez uprawnień właściciela. Członek powinien widzieć
potrzebne sekcje i nie powinien mieć dostępu do operacji spoza swojej
odpowiedzialności.

## Następny krok

Przejdź do [Ustawień](/docs/settings), aby skonfigurować członków, NPC i
szablony map.
