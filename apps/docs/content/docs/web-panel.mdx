Panel pod adresem [lootlog.pl/@me](https://lootlog.pl/@me) porządkuje dane
zebrane przez dodatek. Logujesz się do niego tym samym kontem Discord.

## Zanim zaczniesz

Najpierw wykonaj [Pierwsze kroki](/docs/getting-started). Bez aktywnego dodatku
panel nie odtworzy zdarzeń, które miały miejsce wcześniej.

## Strefa osobista

Strefa osobista dotyczy twojego konta i postaci, niezależnie od wybranego
klanu.

| Widok         | Do czego służy                                   |
| ------------- | ------------------------------------------------ |
| Dashboard     | Podsumowanie aktywności z filtrem świata i czasu |
| Kille         | Historia pokonanych potworów                     |
| Panel walki   | Analiza obsługiwanych walk PvP                   |
| Powiadomienia | Komunikaty związane z kontem                     |
| Ustawienia    | Preferencje i konfiguracja postaci               |

## Strefa organizacji

Po wybraniu klanu nawigacja przełącza się na wspólne dane i narzędzia:

- listę łupów i timery;
- rezerwacje map;
- eventy;
- statystyki i rankingi;
- dokumenty, czat, powiadomienia i logi aktywności;
- członków, role oraz konfigurację.

Zakres widocznych pozycji zależy od [roli i uprawnień](/docs/permissions).
Brak sekcji nie musi oznaczać błędu aplikacji.

## Przełączanie kontekstu

Jeżeli korzystasz z wielu postaci, światów lub klanów:

1. sprawdź aktywne konto w dolnej części nawigacji;
2. wybierz właściwą organizację albo strefę osobistą;
3. ustaw filtr świata;
4. dopiero potem porównuj wyniki.

Każdy klan ma oddzielne dane, role i ustawienia.

## Sprawdź rezultat

Panel jest poprawnie skonfigurowany, gdy pokazuje właściwe konto, pozwala
zmienić świat i wyświetla sekcje zgodne z twoją rolą.

## Następny krok
