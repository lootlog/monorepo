## Pierwsza wersja portalu

Dokumentacja publicznego API game-clienta v1, referencja HTTP w Scalar, osobiste klucze API oraz SDK dla integracji serwerowych. Środowisko deweloperskie służy do weryfikacji przed wydaniem produkcyjnym.

Publiczny obiekt game-clienta zachowuje `apiVersion: 1`. Opublikowane zmiany kontraktów będą opisywane tutaj wraz ze sposobem migracji. Aktualne parametry operacji HTTP sprawdzaj w referencji generowanej ze schematów usług.
