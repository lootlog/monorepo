A server application uses a personal API key. A Margonem add-on uses the installed Lootlog game client. Choose the guide for where your code runs.

## Connect a server application

1. [Create an API key](/keys). Sign in with Discord and select the Organizations your integration needs.
2. [Send your first request](/docs/http). Configure your environment and read Organization data.
3. [Explore the API reference](/reference). Find operations, request parameters, and response schemas for each service.

A key is limited by its selected scope and your current permissions. Read [keys and permissions](/docs/keys) before adding write operations or rotating a key.

## Continue building

Keep server API keys in a secret store. Never put them in userscripts, frontend code, or public repositories.

## Choose your environment

Create separate keys for each environment. Test your integration in development before using production data.

| Environment | Developer portal           | Main API             |
| ----------- | -------------------------- | -------------------- |
| Development | `dev-developer.lootlog.pl` | `dev-api.lootlog.pl` |
| Production  | `developer.lootlog.pl`     | `api.lootlog.pl`     |

The [HTTP guide](/docs/http#2-choose-an-environment) lists the service hosts. Use the [realtime guide](/docs/realtime#authentication) for gateway addresses.

### Local development

The portal is available through Traefik at `http://localhost/developer`, with Vite running on port 3004. You can also open `http://localhost:3004/developer/` directly. If Traefik still uses old rules after a configuration change, run `docker compose restart traefik`.
