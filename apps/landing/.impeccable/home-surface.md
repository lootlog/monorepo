# Home surface brief

- Mode: Persuade
- Audience: Clan decision-maker
- Approved north-star comp: `.impeccable/mocks/guild-broadcast-approved.png`
- Direction: Flat “Clan Broadcast” signal ribbon, broad alternating chapters, real product screenshots as proof.
- Preserve: Product truth, authentication states, installation path, documentation, legal links, Garmory notice, dark mode.
- Reject: 3D, pixel art, characters, detailed fantasy scenes, purple ambience, generic AI imagery, card-grid page structure.

## Fidelity inventory

| Ingredient                                | Production medium                              |
| ----------------------------------------- | ---------------------------------------------- |
| Signal ribbon, timer loops, nodes, alerts | Semantic SVG and CSS                           |
| Persistent cross-chapter broadcast spine  | Semantic HTML and flat color tokens            |
| Dashboard hero proof                      | Existing `dashboard-current.png`               |
| Synchronization proof                     | Existing `battle-panel-current.png`            |
| Guild analysis proof                      | Existing `guild-kill-stats-current.png`        |
| Headline, body, controls, captions        | Semantic HTML with i18n                        |
| Hero motion                               | CSS/Framer Motion with reduced-motion fallback |

The approved comp is a composition reference. Its fake text, placeholder controls, exact proportions, and repeated screenshots must not be literalized.
