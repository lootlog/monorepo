# Oxlint Configuration

This file explains the oxlint configuration for the entire monorepo.

## Rule Categories

### 🔒 Security and Code Quality (Error)

**Core:**

- `eqeqeq` - Enforces `===` instead of `==`
- `no-debugger` - Blocks debugger statements in production
- `no-alert` - Blocks `alert()`, `confirm()`, `prompt()`
- `no-eval` - Blocks unsafe `eval()`
- `no-throw-literal` - Enforces throwing Error objects

**TypeScript:**

- `@typescript-eslint/no-floating-promises` - Enforces Promise handling
- `@typescript-eslint/await-thenable` - Only awaitable values
- `@typescript-eslint/no-misused-promises` - Prevents incorrect Promise usage

**React:**

- `react/jsx-key` - Enforces `key` prop in lists
- `react/jsx-no-duplicate-props` - Prevents duplicate props
- `react/no-children-prop` - Blocks passing children as a prop
- `react/no-direct-mutation-state` - Prevents state mutation
- `react-hooks/rules-of-hooks` - Enforces correct hook usage

**Vitest:**

- `vitest/no-focused-tests` - Blocks `.only()` in tests
- `vitest/valid-expect` - Enforces correct expect() usage

### ⚠️ Warnings (Warn)

**Code Cleanliness:**

- `no-console` - Warns about console usage except `console.warn`, which is explicitly allowed
- `prefer-const` - Prefers const instead of let
- `no-unused-vars` - Unused variables (ignores `_` prefix)

**TypeScript Best Practices:**

- `@typescript-eslint/no-explicit-any` - Avoid `any`, use `unknown`
- `@typescript-eslint/no-unused-vars` - Ignores variables with `_` prefix
- `@typescript-eslint/prefer-nullish-coalescing` - Prefers `??` over `||`
- `@typescript-eslint/prefer-optional-chain` - Prefers `?.` over `&&`
- `@typescript-eslint/consistent-type-imports` - Enforces `import type` for
  symbols used only in type positions

**React:**

- `react/self-closing-comp` - Self-closing tags for components without children
- `react/jsx-curly-brace-presence` - Removes unnecessary `{}`
- `react-hooks/exhaustive-deps` - Dependency array in hooks

**Unicorn (Modern JS):**

- `unicorn/prefer-node-protocol` - Prefers `node:` prefix
- `unicorn/prefer-string-slice` - Prefers `.slice()` over `.substr()`
- `unicorn/better-regex` - Suggests better regex patterns

### ✅ Disabled Rules (Off)

**Intentionally disabled for flexibility:**

- `no-empty-function` - Empty functions allowed (callbacks, abstractions)
- `react/prop-types` - Not using PropTypes (TypeScript)
- `react/react-in-jsx-scope` - Not needed in React 19
- `unicorn/no-null` - `null` allowed (API consistency)
- `unicorn/no-array-for-each` - `.forEach()` allowed

## Special Configuration

### Ignoring variables with `_` prefix

```typescript
const _unusedParam = "OK"; // ✅ No warning
const unusedParam = "BAD"; // ⚠️ Warning

function handleData(_id: string, name: string) {
  // ✅ _id ignored
  return name;
}
```

### Type Imports

```typescript
import type { User } from "./types"; // ✅ Preferred
import { User } from "./types"; // ⚠️ Warning if type-only
```

### Nullish Coalescing

```typescript
const value = data ?? "default"; // ✅ Preferred
const value = data || "default"; // ⚠️ Warning (can be 0, false)
```

## Customization

### Per-file ignores

```typescript
/* oxlint-disable no-console */
console.log("Allowed in this file");
```

### Inline ignores

```typescript
// oxlint-disable-next-line no-explicit-any
const data: any = fetchLegacyAPI();
```

## CI/CD Integration

In CI, you can use `--deny-warnings` for stricter mode:

```bash
pnpm oxlint --deny-warnings
```
